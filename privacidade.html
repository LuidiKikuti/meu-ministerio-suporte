Política de Privacidade

Meu Serviço de Campo

Esta Política de Privacidade explica como o aplicativo Meu Serviço de Campo lida com as informações utilizadas durante o seu funcionamento.

Dados armazenados

Os registros criados pelo usuário, incluindo atividades, horas, pessoas, revisitas, estudos, observações e configurações, são armazenados localmente no dispositivo.

O aplicativo não exige a criação de uma conta e não possui um servidor próprio para armazenar esses registros.

Localização

O acesso à localização ocorre somente quando o usuário escolhe utilizar recursos que dependem dela, como salvar a localização de uma pessoa ou visualizar informações no mapa.

As coordenadas salvas pelo usuário permanecem nos dados locais do aplicativo.

Mapas

A visualização do mapa utiliza serviços de mapas fornecidos pela plataforma. Esses serviços podem processar informações técnicas necessárias para apresentar o mapa, de acordo com as políticas do respectivo provedor.

Notificações

O aplicativo pode criar notificações locais para lembretes de revisitas e estudos. Esses lembretes são processados no próprio dispositivo.

Backup e exportação

O usuário pode criar backups ou exportar informações. O compartilhamento ou armazenamento externo desses arquivos acontece somente quando o usuário escolhe realizar essa ação.

Publicidade e rastreamento

O aplicativo não exibe anúncios e não utiliza os dados registrados no app para rastreamento publicitário.

Compartilhamento de dados

O desenvolvedor não vende os dados pessoais registrados pelo usuário.
